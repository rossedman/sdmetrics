systemd v260+ report framework

systemd metrics for Go and OpenTelemetry

Publish your daemon's metrics under /run/systemd/report/ in a few lines, then export every source on the host, systemd's own included, as OTLP or Prometheus, each attributed to the unit that produced it. Pure Go, no cgo.

Get started Export a host GitHub
$ go get github.com/rossedman/sdmetrics@latest
sdmetrics-exporter -once
SOURCE              UNIT
io.systemd.Manager  init.scope
io.systemd.Network  systemd-networkd.service
io.example.Queue    queued.service

FAMILY                               VALUE
Manager.UnitsByTypeTotal{type=service} 142
Network.OperationalState{eth0}  "routable"
Queue.JobsProcessed{result=ok}         9120
